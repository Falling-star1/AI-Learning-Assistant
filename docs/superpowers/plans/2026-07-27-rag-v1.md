# RAG V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first runnable RAG flow for course document upload, local retrieval, and fallback answering without requiring an API key.

**Architecture:** Document parsing, splitting, retrieval storage, and question answering live in separate `modules/rag` files. The agent router saves uploaded files, builds the knowledge base, retrieves context, and sends it through the pluggable LLM Provider layer.

**Tech Stack:** Python, unittest, local JSON retrieval store, optional pypdf/python-pptx loaders, Streamlit upload objects.
