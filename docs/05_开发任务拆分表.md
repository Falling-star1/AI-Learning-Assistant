# AI 多模态学习助手开发任务拆分表

## 1. 开发阶段安排

项目开发周期建议为 2 到 3 周，优先保证核心功能完整可演示，再逐步增加加分功能和争优亮点。

| 阶段 | 时间建议 | 阶段目标 | 主要产出 |
|---|---|---|---|
| 第 1 阶段 | 第 1-2 天 | 明确需求、确定技术路线、搭建项目框架 | 需求文档、架构图、项目目录、运行环境 |
| 第 2 阶段 | 第 3-6 天 | 完成文件上传、资料解析和 RAG 知识库 | 文件解析模块、向量数据库、知识库问答 |
| 第 3 阶段 | 第 7-10 天 | 接入大模型和学习辅助生成能力 | LLM 问答、课程总结、报告大纲生成 |
| 第 4 阶段 | 第 11-14 天 | 完成 YOLO 检测和 Agent 调度 | 图片检测、检测结果分析、任务自动路由 |
| 第 5 阶段 | 第 15-18 天 | 完成前端优化、历史记录和系统联调 | 可演示系统、对话历史、稳定交互流程 |
| 第 6 阶段 | 第 19-21 天 | 准备提交材料和答辩展示 | 演示视频、课程报告、陈述 PPT、代码压缩包 |

## 6. 报告首页项目简介示例

本项目设计并实现了一个 AI 多模态学习助手，支持课程资料上传、RAG 知识库问答、图片目标检测和学习辅助内容生成。系统通过 Agent 判断用户意图，并自动调用知识库检索、大语言模型问答和 YOLO 检测等工具。项目综合应用了深度学习、目标检测、大模型、RAG 和智能体调度等课程知识，能够帮助学生高效管理课程资料、理解知识点并生成学习总结。系统第一阶段采用 Streamlit 快速实现可演示版本，后续可升级为 Vue + FastAPI 工程化架构。

成员 A 负责前端页面、聊天交互、文件上传、结果展示和演示视频录制；成员 B 负责 RAG 知识库、Embedding、向量数据库、LLM 问答和 Prompt 设计；成员 C 负责 YOLO 目标检测、Agent 调度、SQLite 数据库、接口联调和环境配置。成员 A：成员 B：成员 C = 3.3：3.4：3.3。
