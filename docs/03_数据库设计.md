# 数据库设计

## 设计目标

V1 使用 SQLite 保存轻量级数据，满足课程演示中的对话历史、文件记录和后续报告生成追踪。数据库文件位于 `data/sqlite.db`。

## 核心表

### chat_history

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PRIMARY KEY AUTOINCREMENT | 记录编号 |
| session_id | TEXT NOT NULL | 会话编号 |
| role | TEXT NOT NULL | user / assistant / system |
| content | TEXT NOT NULL | 消息内容 |
| mode | TEXT NOT NULL | 任务模式，如课程资料问答、普通问答 |
| provider | TEXT NOT NULL | 使用的 LLM Provider，如 fallback / cloud / ollama |
| created_at | TEXT NOT NULL | 创建时间 |

### file_records

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PRIMARY KEY AUTOINCREMENT | 文件编号 |
| file_name | TEXT NOT NULL | 原始文件名 |
| file_type | TEXT NOT NULL | pdf / image / txt 等 |
| storage_path | TEXT NOT NULL | 本地保存路径 |
| status | TEXT NOT NULL | uploaded / indexed / failed |
| created_at | TEXT NOT NULL | 创建时间 |

## 设计说明

- 用户上传文件存放在 `data/uploads/` 或 `data/images/`。
- 向量索引存放在 `data/vector_db/`，SQLite 只记录文件元信息。
- RAG 资料上传并完成建库后，`file_records.status` 记录为 `indexed`。
- 对话历史可用于恢复会话，也可作为报告生成的上下文来源。
